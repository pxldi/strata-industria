# Strata Industria

> Minecraft technology progression mod. Mod id: `strataindustria`.

A single, cohesive technology mod for Minecraft that takes you from knapping flint in the dirt
to running a fully automated industrial base, where every tier changes how you play. Inspired by
GregTech New Horizons, TerraFirmaGreg and Vintage Story.

See [docs/design.md](docs/design.md) for the full progression design.

## Status

Early development. Nothing playable yet; the first milestone covers tiers 0 to 2
(stone age to a full bronze kit).

## Development

Requirements: a JDK 25 (Gradle downloads one automatically if missing) and an IDE with Gradle
support (IntelliJ IDEA recommended).

```sh
./gradlew runClient      # start a dev client with the mod loaded
./gradlew runServer      # start a dev dedicated server
./gradlew runData        # regenerate models, blockstates, lang, tags, recipes, loot tables
./gradlew runGameTestServer
./gradlew build          # build the jar into build/libs
```

Generated resources are committed. After changing anything under `datagen/`, run
`./gradlew runData` and commit `src/generated`. On pull requests from this repository, CI
regenerates them and commits the result to the branch if they are out of date (pull before your
next push); on `main` and on forks it fails instead.

### Project layout

```
src/main/java/dev/strataindustria/
  StrataIndustria.java          mod entry point
  Config.java            common config
  client/                client-only setup
  registry/              blocks, items, creative tabs
  datagen/               data generators (models, lang, tags, recipes, loot)
src/main/resources/      hand-made assets (textures)
src/generated/resources/ generated assets and data (do not edit by hand)
src/main/templates/      neoforge.mods.toml template
```

### Renaming the mod

```sh
scripts/rename-mod.sh <new_mod_id> "<New Display Name>" [NewMainClassName]
```
